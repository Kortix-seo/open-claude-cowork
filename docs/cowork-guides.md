# Three comparisons before a team picks an open-source base

This repository, `Kortix-seo/open-claude-cowork`, is a checked list of open-source and self-hostable Claude Cowork alternatives, each entry read from its own pages. Three comparisons settle what kind of base a team needs first.

## A desktop, or a server

Where the work runs decides this one, and [the OpenWork comparison](https://opensourceclaudecowork.com/claude-cowork-vs-openwork) covers it. OpenWork is a free app for macOS, Windows and Linux built on OpenCode, with files staying on your machine. A desktop suits one person working through their own files; a server is what a team can govern and put a second reviewer in front of.

## A coding tool, or a system

Which job it serves is a separate question, worked through in [the Claude Code comparison](https://opensourceclaudecowork.com/claude-cowork-vs-claude-code). Claude Code is built for software engineering, reads `CLAUDE.md` from the repo and runs on a paid plan, while Cowork's knowledge work shares the same app since the September 2026 merge. Kortix carries both jobs in one repo, and OpenCode is the harness.

## Self-hosted, and how far that reaches

[The self-hosted Claude Code comparison](https://opensourceclaudecowork.com/self-hosted-claude-code) shows how far that word reaches. In Anthropic's public beta a runner sits inside your network while the control plane, the queue and the transcript stay with Anthropic. Kortix runs the stack on your hardware, with each session on a managed sandbox off the box. One isolated sandbox per session. Each session has its own isolated machine and branch.

The repository's `docs/` is where each candidate is checked against its own documentation, page by page, before it earns a line on the list.
